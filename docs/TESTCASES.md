# fam — 测试用例清单

覆盖账户管理、录入、统计走势、导出备份、系统能力五条核心路径。
后端用例在 `server/internal/api/*_test.go`（httptest + 临时 SQLite 文件），前端校验用例在 `tests/frontend/validate.test.js`（node:test）。

| C12 | 指定 date 汇总（历史某天总资产） | 使用当日 carry-forward 结果 |
| C13 | 按币种过滤统计 | 仅统计该币种账户 |
| C14 | 负数账户（负债）计入总资产 | 总额正确减少 |
